# Reference implementation

`Service.qml` is a frozen copy of the QML service the native app was ported
from — the Qt/Windows port of the Omarchy Quickshell plugin, at the commit the
port was taken from (`164243b`). The Qt front end itself has been removed from
this repository; this file is kept **only** as the fixture for the differential
test.

`Tools/qml-reference.js` extracts its report functions and executes them under
node, and `test-macos.sh` diffs the result against the Swift implementation.
That is what holds the Swift port to the original's behavior, including the
history JSON format the file defines.

Do not edit this file to make a test pass. It is the reference; if the Swift
side disagrees, the Swift side is wrong — or the behavior change is deliberate,
in which case update both and say so in the commit.
